#  Mobile Sales Dashboard (Power BI)

##  Overview

This project is an interactive Power BI dashboard built to analyze mobile sales performance, customer behavior, and trends.

##  Key Features

* KPI Cards (Total Sales, Quantity, Rating, Price)
* Sales by City (Map)
* Sales by Day & Month trends
* Customer Ratings Analysis
* Sales by Mobile Model
* Payment Method Distribution
* MTD & Yearly Comparison

---

##  Tools Used

* Power BI
* DAX
* Excel

##  Files Included

##  Insights

* Top brands: Apple, Samsung
* Sales trends vary across months
* Customer ratings mostly fall under “Best”
* Daily sales pattern helps identify peak days
